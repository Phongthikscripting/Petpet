# Privacy policy

This program stores user data for the only purpose to create and upload an image to the service Discord. Once this purpose is fullfilled, the data is deleted. No information that can be traced back to any user is stored in the program's logs.

## Opt-out of the bot
You may opt-into a blacklist at any time, which will prevent your user from being used as a target of the program's commands.
Email the bot administrator at lumap@duck.com if you want to do so.
